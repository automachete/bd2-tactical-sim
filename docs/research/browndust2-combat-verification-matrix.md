# BrownDust2 戦闘・実機検証マトリクス

最終確認日: 2026-09-04（Asia/Tokyo）

## 1. 完了条件

この文書は、戦闘仕様の確定根拠、実装検証、実機トレースの要否を管理する。公開文献・公式データ・再現可能な原表から期待結果を一意に決められる項目は出典と採用規則を記録する。乱数相関、同値イベント順、同一アクション内の再評価など、文献が結果を定義しない項目は実機トレースで確定する。

実機照合を行う場合、各ケースは次の一式がそろったときだけ `VERIFIED` とする。

- クライアントビルド番号、コンテンツ、難易度、日時
- 味方・敵・コスチューム・装備・成長値の完全な入力
- 初期盤面、行動順、使用スキル、バースト段階
- 各ヒット前後のHP、SP、チェイン、効果、CT、座標
- 乱数の影響を排除したケース、または十分な反復と全結果
- 画面録画または連続スクリーンショット
- シミュレータのイベントログとの差分がゼロであること
