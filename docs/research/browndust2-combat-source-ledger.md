# BrownDust2 戦闘仕様・出典台帳

最終確認日: 2026-09-01（Asia/Tokyo）

## 1. 目的

この台帳は、`rpg-simulator-conceptual-design.md` に採用した戦闘仕様の根拠、根拠の強さ、確認日を追跡するための資料である。設計書は最新仕様だけを記述し、旧仕様との互換レイヤーは持たない。

根拠の優先順位は次のとおりとする。

1. 現行クライアントの同一入力に対する観測結果
2. 韓国公式ラウンジの最新アップデート告知・ゲームガイド
3. 韓国公式の開発者ノート
4. 投稿日が新しく、計算過程・画面・動画を示す韓国コミュニティ資料
5. 上記を補う二次資料

公式記述と現行クライアントが食い違う場合は、現行クライアントを採用し、再現用の入力・乱数・画面値を回帰テストとして保存する。コミュニティ資料だけで得た仕様は、最低1件の独立した実機トレースで確定させる。

信頼度は次の基準で付ける。

| 等級 | 意味 | 採用方法 |
|---|---|---|
| A | 基準日時点の韓国公式告知・公式ガイド、または同等の現行一次資料 | 原則として現行仕様に採用する |
| A- | 公式原稿だが初期案・シーズン依存値・転載経由を含む | 不変構造だけ採用し、可変値は現行シーズンデータへ分離する |
| B+ | 新しい韓国資料で、計算過程、画面、動画、または複数資料による追認がある | 設計へ採用し、実装受け入れ時に実機トレースで固定する |
| B | 新しい韓国攻略資料として整合するが、独立追試が不足する | データ形状・検証仮説として採用し、境界値は断定しない |

## 5. 採用した確定仕様と根拠対応

| 仕様 | 根拠 | 設計上の扱い |
|---|---|---|
| 標準盤面は各陣営3×4 | O-05 | `GridDefinition(3,4)` |
| 標準編成は最大5キャラクター | K-07、現行クライアント | `party_capacity=5` |
| 一般PvE初期SPは15 | K-06、K-11 | 標準値15。ただし遭遇定義で上書き可能 |
| 鏡戦争は攻撃側5、守備側6、各ターン6回復、攻撃側先手 | K-02、K-03 | `mirror_war` の固定ルール |
| 防御・魔法抵抗の実効上限は90% | K-09、現行画面検証対象 | 表示値と実効値を分離し、デバフ適用後に上限処理 |
| 有利属性は基礎+30%。属性ダメージ増加は有利時だけ加算 | K-08 | 属性行列と属性ダメージ項を分離 |
| 火・水・風の属性不利は0.5倍 | K-13 | 属性行列の不利係数を0.5とする |
| チェインは1ごとに基礎10%増加 | K-05 | 命中前の現在チェイン数を使用し、命中後に増加 |
| 途中計算で小数点以下切り捨てが存在 | K-05、K-13 | 算術パイプライン各指定境界で整数化 |
| 超過クリ率1%はクリダメ6%へ変換 | K-05 | クリ率集計後、100%超過分を6倍してクリダメへ加算 |
| バーストは最大3段階、追加SP、段階別に効果・範囲・打撃数も変化可能 | O-03 | 単なる倍率ではなく、スキル定義の完全な派生形として扱う |
| ゴールデンコロシアムはコスチューム単位、同一人物の複数衣装を同時配置可 | O-06、K-01 | 通常のキャラクター一意制約を解除し、駒IDをコスチューム単位にする |
| ゴールデンコロシアムは装備非反映 | O-06、K-01 | 成長値合成時に装備層を除外 |
| ゴールデンコロシアムは1体ずつ交互行動、先後ランダム、双方行動でALLターン+1 | O-06 | 専用スケジューラ |
| ゴールデンコロシアムは無限SP・CTなし・通常はスキル、沈黙/デスタイム時は通常攻撃 | O-06 | 専用合法手とフォールバック |
| ゴールデンコロシアムのチェインは戦闘終了まで維持 | O-06 | `chain_reset=never_until_battle_end` |
| 魔物追跡者は部位別ターゲット・弱点・条件スキルを持つ | K-03、K-11 | ボス本体と複数のターゲットノードを分離 |
| 魔物追跡者Lv.1–5は1編成、Lv.6以降は2編成 | K-04 | 連続エピソードとして編成交代を扱う |
| 魔物追跡者の各Lv.HPは累積撃破閾値で、選択Lv.表示HPから総与ダメージを引く | K-04、D-03 | `cumulative_hp_by_level` と差分区間を分離し、Lv.HPの再合算を禁止 |
| 現行キメラはLv.1～25、8部位、S1～S4とC1、初期SP15、回復SP5 | D-03 | 開催シナリオ生成時に外部データから構築し、定数化しない |
| 標記中の対象は回避できない | K-14 | `MARK` 効果を対象へ保持し、回避抽選前に無効化する。回避チャージは消費しない |
| モルフェア召喚物は召喚者能力と選択衣装強化を継承する | K-15、D-01 | 召喚時に召喚者の合成済み基礎能力、発動衣装の強化段階、召喚順序を固定する |
| 暴走は残SPを全消費し追加消費分だけ倍率へ加算する | K-16、D-01 | 基礎コストと追加消費を分離し、`EXTRA_SP_CONSUMED` を倍率ソースにする |
| ノックバックスキルの衝突係数は衣装・強化・潜在力ごとに異なる | D-01 | `collision_coefficient_bp` を各スキル派生へ格納し、通常行動の25%を流用しない |
| マルチフェーズ戦闘はフェーズ間でボスのバフ/デバフを継承せず、フェーズ中デスタイムなし | O-03 | フェーズ遷移イベントで指定カテゴリを消去 |

## 6. 断定せず実機で確定する項目

公開情報だけでは「完璧な再現」に足りない次の項目は、`browndust2-combat-verification-matrix.md` に再現手順を定義している。

- 同一優先度イベントの総順序
- 多段攻撃のクリティカル・回避抽選単位
- 効果付与とダメージの前後関係、死亡時・復活時・反撃時の割り込み順
- バフ/デバフの同種重複、上書き、延長、解除対象タグ
- ノックバックの衝突、盤外、死亡、占有解消の全組合せ
- 属性不利側の最終係数と、光・闇の被ダメージ処理
- 防御/魔法抵抗の下限、負値領域、固定ダメージ・消耗ダメージの除外項
- ターゲット探索の行循環、挑発・集中・ロックオンが競合した場合の優先順
- SP回復、CT、持続ターンの減算タイミング
- モード別の引き分け、同時全滅、デスタイム、スコアの同値処理

## 7. 更新手順

1. 韓国公式ラウンジのメンテナンス・アップデート告知を確認する。
2. 戦闘仕様に影響する変更だけを抽出し、現行クライアントで最小ケースを記録する。
3. 本台帳の根拠行と確認日を更新する。
4. データスナップショット、ゴールデントレース、設計書を同じ変更で更新する。
5. 旧仕様の分岐は残さず、旧ゴールデントレースは履歴資料としてテスト対象外へ移す。
