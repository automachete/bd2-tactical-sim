# BrownDust2 戦闘仕様・出典台帳

最終確認日: 2026-09-04（Asia/Tokyo）

## 1. 目的

この台帳は、`rpg-simulator-conceptual-design.md` に採用した戦闘仕様の根拠、根拠の強さ、確認日を追跡するための資料である。設計書は最新仕様だけを記述し、旧仕様との互換レイヤーは持たない。

根拠の優先順位は次のとおりとする。

1. 現行クライアントの同一入力に対する観測結果
2. 韓国公式ラウンジの最新アップデート告知・ゲームガイド
3. 韓国公式の開発者ノート
4. 投稿日が新しく、計算過程・画面・動画を示す韓国コミュニティ資料
5. 上記を補う二次資料

公式記述と現行クライアントが食い違う場合は、現行クライアントの結果を採用し、再現用の入力・乱数・画面値を回帰テストとして保存する。決定論的な外部可観測規則は、公式文書・公式データ、または現行日付と計算過程を備えた整合する資料から確定する。資料間の矛盾、乱数の抽選単位、同値イベントの総順序、同一アクション途中の再評価は実機トレースで確定する。

信頼度は次の基準で付ける。

| 等級 | 意味 | 採用方法 |
|---|---|---|
| A | 基準日時点の韓国公式告知・公式ガイド、または同等の現行一次資料 | 原則として現行仕様に採用する |
| A- | 公式原稿だが初期案・シーズン依存値・転載経由を含む | 不変構造だけ採用し、可変値は現行シーズンデータへ分離する |
| B+ | 新しい攻略資料で、計算過程、画面、動画、または複数資料による追認がある | 決定論的な外部可観測規則は設計へ採用し、出典回帰で固定する |
| B | 新しい攻略資料として公式基本規則と整合するが、独立追試が不足する | 明記された規則は採用できる。資料が述べない境界値を補間しない |

## 5. 採用した確定仕様と根拠対応

| 仕様 | 根拠 | 設計上の扱い |
|---|---|---|
| 標準盤面は各陣営3×4 | O-05 | `GridDefinition(3,4)` |
| 標準編成は最大5キャラクター | K-07、現行クライアント | `party_capacity=5` |
| 一般PvE初期SPは15 | K-06、K-11 | 標準値15。ただし遭遇定義で上書き可能 |
| 鏡戦争は攻撃側5、守備側6、各ターン6回復、攻撃側先手 | K-02、K-03 | `mirror_war` の固定ルール |
| 鏡戦争のオート戦闘は予約スキルを実行し、モード固有資料が上書きするのはSPと先制処理 | O-12、K-19 | 予約時に確定したスキルとSP費用を実行し、死亡者は予約列から飛ばす |
| 防御・魔法抵抗の実効上限は90% | K-09、現行画面検証対象 | 表示値と実効値を分離し、デバフ適用後に上限処理 |
| HPが0になると死亡し、通常回復と明示的な復活を区別する | O-10、D-01 | `DEAD` を通常回復の対象外とし、復活命令だけが復帰させる |
| 主対象はFront/Skipと行優先で決まり、範囲は主対象基準で適用する | K-18、D-01 | 探索とローカル範囲変換を共通ネイティブ処理にし、選択表示と実行で同じ結果を使う |
| 盤外へのノックバックは不発。衝突は押し手HPの上限50,000と個別係数を使い、回避・ボス・墓石に例外がある | K-18、D-01 | 移動可否、衝突対象、衝突ダメージを別段階で解決する |
| 有利属性は基礎+30%。属性ダメージ増加は有利時だけ加算 | K-08 | 属性行列と属性ダメージ項を分離 |
| 火・水・風の属性不利は0.5倍 | K-13 | 属性行列の不利係数を0.5とする |
| チェインは1ごとに基礎10%増加 | K-05 | 命中前の現在チェイン数を使用し、命中後に増加 |
| 途中計算で小数点以下切り捨てが存在 | K-05、K-13 | 算術パイプライン各指定境界で整数化 |
| 超過クリ率1%はクリダメ6%へ変換 | K-05 | クリ率集計後、100%超過分を6倍してクリダメへ加算 |
| 固定・純粋・消耗ダメージは、防御・被ダメージ・エネルギーガード・クリティカル等の参照項が互いに異なる | K-18 | 単一の`true_damage`フラグへ潰さず、種別ごとの算術パイプラインを持つ |
| エネルギーガードは追加HP層として消費され、純粋・消耗ダメージは貫通する | K-18 | 本体HPとガード残量を分離し、ダメージ種別で参照先を選ぶ |
| バーストは最大3段階、追加SP、段階別に効果・範囲・打撃数も変化可能 | O-03 | 単なる倍率ではなく、スキル定義の完全な派生形として扱う |
| ゴールデンコロシアムはコスチューム単位、同一人物の複数衣装を同時配置可 | O-06、K-01 | 通常のキャラクター一意制約を解除し、駒IDをコスチューム単位にする |

文献が通常は公開しない次の内部境界だけを、`browndust2-combat-verification-matrix.md` の制御入力で採取する。

- 多段・多対象クリティカルと回避の抽選単位・相関・チャージ消費単位

- ランダム先後の分布と観測可能なシード位置
- 同一アクション途中で主対象が死亡した後の範囲再取得
- 衝突死、反撃、復讐、追撃、復活、死亡時効果が同値発火した場合の総順序と再帰
